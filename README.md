# cope: shots and saves, more or less

Real live football stats. Points only (demo, no real money). 18+.

## Run it
1. Install Node.js 22 LTS from https://nodejs.org
2. In this folder: `npm install`
3. Practice matches (no key needed): `npm run test-mode`, then open http://localhost:3000
4. Real live stats: copy `.env.example` to `.env`, paste your API-Football key, then `npm start`

See the full guide for every step.
